# 🎮 Game Glitch Investigator: The Impossible Guesser

## Overview

This project repairs a buggy Streamlit number guessing game that was generated by an AI. The starter code had several glitches:

- guesses outside the difficulty range were accepted,
- the hint text was inverted,
- the new game reset did not clear state correctly,
- some game logic was mixed directly into `app.py`.

The final fix moves core game logic into `logic_utils.py`, adds validation and testing, and documents the debugging process.

## Setup

1. (Optional) Create and activate a virtual environment:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
2. Install dependencies:
   ```bash
   python3 -m pip install -r requirements.txt
   ```
3. Run the app:
   ```bash
   python3 -m streamlit run app.py
   ```

## Demo Walkthrough

1. Select a difficulty in the sidebar: Easy, Normal, or Hard.
2. Enter a guess inside the input field and click `Submit Guess 🚀`.
3. The app responds with:
   - `📉 Go LOWER!` when the guess is too high,
   - `📈 Go HIGHER!` when the guess is too low,
   - `🎉 Correct!` when the guess matches the secret.
4. If the guess is outside the current difficulty range, the app rejects it with a clear error.
5. Click `New Game 🔁` to start fresh with a new secret, reset attempts, score, and cleared history.

## Fix Summary

- Refactored game logic into `logic_utils.py`.
- Implemented difficulty-specific range validation.
- Corrected the hint messages to match the comparison.
- Reset session state properly when a new game starts.
- Added pytest coverage for validation and hint logic.
